## 10/2：草原曲水 → 林区小城

**住宿：** 根河市区。**基础驾驶：** 3小时50分。

**优先级：** 莫日格勒河 > 根河市区短逛；额尔古纳湿地仅作替换。

07:30出发；上午曲水观景；额尔古纳午餐；下午到根河，入住后按精力短逛。

1. **[优先] 莫日格勒河曲水观景｜2–2.5小时**

   选择一个主观景区域，看河流弯道和草原层次。南游客中心方案与曲水云天方案二选一；入口、停车方式临行确认。拍照可先拍曲水全景，再拍河流与草原细节。

   车程口径：原高德表仅到南游客中心；若改曲水云天，首日转场约291.9公里、4小时14分，另加游览。

2. **[用餐] 额尔古纳午餐｜45–60分钟**

   安排正常午餐及休息，可选列巴、汤或当地家常菜；不为特定网红店绕路排队。

   车程口径：原路线已途经额尔古纳，具体餐厅接驳另计。

3. **[可选] 根河冷极广场／市区短逛｜20–30分钟**

   到达根河后再决定，感受林区小城；不要专门绕去远处冷极村。晚餐可安排铁锅炖。

   车程口径：市区接驳未计入原高德表。

4. **[替换] 额尔古纳湿地景区｜约2小时**

   只有更想看湿地、愿意明显缩短或替换莫日格勒河时才加入；不要把完整湿地游叠加在转场日。不是另一个更远的国家湿地公园。

   车程口径：景区支线未核查；加入需重新调整首日时间。

**删减顺序：** 时间紧时先取消根河市区短逛；首日不再增加兴安神鹿园。

## 10/3：觉乐驯鹿 → 根白森林 → 莫尔道嘎

**住宿：** 莫尔道嘎镇。**基础驾驶：** 2小时10分。

**优先级：** 觉乐与根白公路为重点；得耳布尔午餐，车站和龙山按兴趣增减。敖鲁古雅是觉乐的替换方案。

早餐后从根河出发，觉乐喂鹿 → 根白公路短停 → 得耳布尔午餐 → 车站（可选）→ 莫尔道嘎 → 龙山（可选）。含车站和龙山短走，全日建议6–8小时；登顶或改敖鲁古雅需重新取舍。

**开放提醒：** 兴安神鹿园暂不排入固定行程：9月26日和29日亲访记录反馈道路受阻／未能进入，尚无可靠的恢复开放证明。不是认定今天必定关闭；确认开放后再考虑。

1. **[优先] 觉乐驯鹿园：林间喂鹿｜60–90分钟**

   建议把这里作为当天的喂鹿点，与敖鲁古雅二选一。10月2日亲访笔记记录游玩约1小时、门票35元、苔藓20元，价格和营业以现场为准。按工作人员指引互动，留意鹿角。若已在敖鲁古雅完成喂鹿，可直接跳过。

   车程口径：高德10/3 08:33：根河市政府 → 觉乐16.0公里，18分41秒（约19分钟）。本次核到园区POI，未核实独立停车入口。

2. **[优先] 根白公路：森林沿途短停｜合计45–75分钟**

   把风景留给行车途中，在允许停车的位置挑2–3处短停。近期笔记已有落叶与初雪，现场可能是疏林秋色，不保证整片金黄。未核实独立观景停车场，不在行车道或铁路上拍照。这里的时长仅为下车停留。

   车程口径：高德10/3 08:33：觉乐 → 得耳布尔镇政府63.0公里，1小时02分03秒；得耳布尔 → 莫尔道嘎镇政府44.7公里，48分37秒。拍照停留另加。

3. **[用餐] 得耳布尔镇：午餐与补给｜45–60分钟**

   在镇上吃午餐、休息，再继续去莫尔道嘎。旧笔记提到姗姗馅饼，可作现场找店线索；具体餐厅还未确定，按当天营业和停车方便程度选择。

   车程口径：路线途经点采用得耳布尔镇政府。具体餐厅接驳未核查，不计入已核主线驾驶时间。

4. **[可选] 得耳布尔站：站前外观｜10–15分钟**

   对林区铁路感兴趣时，顺路看站房外观、在允许通行的站前街道散步。不承诺进入站台，也不安排铁轨拍照。没有兴趣可跳过。

   车程口径：高德10/3 08:30：镇政府 → 车站1.1公里，2分42秒；08:35车站 → 莫尔道嘎45.6公里，51分52秒。整线加车站比基础方案多2.9公里、9分29秒驾驶，连停留共多留20–25分钟。

5. **[可选] 龙山公园：抵达后步行登高｜短走45–75分／登顶往返90–120分**

   到莫尔道嘎后看天气与体力决定。时间充裕可走完整登高路线，时间少就短走后折返；两种时长不叠加。近期实走笔记支持完整往返约1.5–2小时。建议步行，不照搬后山驾车登顶路线。

   车程口径：高德10/3 08:35：莫尔道嘎镇政府 → 龙山公园POI 1.3公里，3分17秒，仅到公园导航点，不含上山。独立步行入口尚未核实。

6. **[替换] 敖鲁古雅：文化参观＋驯鹿｜2.5–3小时**

   更想了解使鹿文化时，用敖鲁古雅替换觉乐，建议文化展陈、鹿苑与园内接驳共留2.5–3小时。两处喂鹿不必都去；选此方案时缩减龙山或沿途停留。博物馆与鹿苑入口、票务以现场为准。

   车程口径：高德10/3 08:30：根河市政府 → 敖鲁古雅停车场3.9公里，6分41秒；敖鲁古雅 → 得耳布尔81.2公里，1小时20分19秒。经敖鲁古雅、得耳布尔到莫尔道嘎整线130.0公里、2小时16分23秒，不含游览。

7. **[可选] 守望桥晨景｜30–45分钟**

   若住宿近、天气合适，到允许步行的位置看河流和晨光。晨雾不保证出现，不照搬帖子5点到场的时间。

   车程口径：仅在住宿附近、方便步行时安排；酒店到桥的驾车接驳尚未核查，未给出车程。

**删减顺序：** 先取消站前和龙山；已喂过鹿则跳过觉乐。保留根白公路与正常午餐，森林公园和白鹿岛仍放在次日。

## 10/4：红豆坡 · 一目九岭 → 白鹿岛

4. **[优先] 九卡—七卡北段卡线观景｜停车合计30–45分钟**

   选2–3处允许停车的开阔位置看界河与河谷。只在开放区域停车，不攀越围栏或进入农田草垛；树叶状态依现场，不以夏季麦田照片承诺十月景观。

   车程口径：按奥利亚列巴房→九卡→七卡逐段导航，采用10/4高德查验。完整路线与分段分别查询，不直接相加替代整线。

5. **[推荐] 七卡入住、村内散步与晚餐｜入住休息约30分；晚餐约60分**

   仍住七卡。先入住，再按住宿方供餐安排吃晚饭；兰妮农家院是村内另一候选，可问现包饺子和当季蔬菜。实吃依据为2025年国庆记录，出发前请向店家确认是否供餐。

   车程口径：主线终点仍用七卡戍边食府作村内参考，保持次日路线衔接；具体民宿与兰妮餐厅间的接驳另核。

6. **[可选] 老鹰嘴：额外河谷观景｜20–30分钟；连额外驾驶约多1小时**

   仅在开放与停车条件合适、时间充裕时加入；不采用旧帖车速或未经允许的入口。若加入，缩减室韦和卡线停车。

   车程口径：高德已分别查询带老鹰嘴与不带老鹰嘴的完整路线，新增驾驶约27分钟；精确整线差值见分段车程。

7. **[替换] 太平林场：林曦农家菜午餐｜60–75分钟，替换临江午餐**

   提前饿了或临江餐厅不开时，改在太平吃东北家常菜、当季蔬菜。旧亲历有实吃支持，当前营业先确认；两顿完整午餐不叠加。

   车程口径：高德10/4 08:28：白鹿岛停车场→林曦95.2公里、1小时19分26秒；林曦→临江31.0公里、33分37秒，基本沿白鹿岛到临江的路线。

**删减顺序：** 时间紧先取消白鹿岛晨景和老鹰嘴，再缩短室韦列巴排队及卡线停车；保留正常午餐与七卡入住。临时封路时按现场允许的路线重算，不强行穿行。

## 10/6：七卡南段观景 → 黑山头 → 额尔古纳

**住宿：** 额尔古纳市区。**基础驾驶：** 2小时04分。

**优先级：** 南段卡线慢看为重点；乌兰山观景与黑山头骑马二选一，下午回额尔古纳休息。

早餐后09:00左右从七卡出发；沿南段卡线观景，黑山头午餐；乌兰山与骑马最多选一项，15:00–15:30左右离开黑山头，争取16:30前到额尔古纳。

1. **[优先] 七卡早餐＋南段卡线观景｜早餐30–45分钟；停车观景45–60分钟**

   早餐优先住宿自带餐食或二姐面馆，营业时间提前问清。沿七卡至黑山头方向行驶，挑开放停车区看河谷与草原，不再折返九卡和室韦。

   车程口径：七卡至黑山头基础1小时19分；当天全程130.3公里、2小时04分，观景与用餐另计。

2. **[二选一] 乌兰山河湾观景｜45–60分钟**

   偏爱风景摄影时考虑，先确认当日开放和入口。加入这一项就不安排骑马，避免重新把一天排满。

   车程口径：景区入口支线和内部接驳未计入主线；实际选定入口后再导航。

3. **[二选一] 黑山头正规马场短体验｜连准备约60分钟**

   偏爱参与式体验时选择这一项，提前约短时段，确认头盔、教练和实际骑乘时长。天气不适合则取消，午餐后从容返城。

   车程口径：具体马场待选，支线另计；不安排2–3小时长线骑行。

4. **[推荐] 黑山头午餐＋额尔古纳入住休息｜午餐45–60分钟；入住后自由安排**

   在黑山头正常吃午餐，按预约把骑马放在午餐前或后。下午到额尔古纳，散步、晚餐并整理行李，确认次日还车门店。当天不追黑山头日落。

   车程口径：黑山头至额尔古纳0小时46分；市区餐厅与酒店接驳另计。

**删减顺序：** 有延误先取消乌兰山／骑马，再缩短观景停车；保留午餐和下午返城，不追加完整湿地游。

## 10/7：早餐 → 海拉尔还车

**住宿：** 15:00 前海拉尔还车。**基础驾驶：** 1小时34分。

**优先级：** 按时返程 > 市内短逛；不安排城外景区。

早餐后09:00左右离开额尔古纳；计划中午抵达海拉尔；午餐、加油后14:00左右到还车点，15:00前完成。

1. **[优先] 额尔古纳早餐与返程｜早餐30–45分钟；驾驶留2.5–3小时**

   整理行李，检查还车要求后出发。高德复查至海拉尔站约1小时34分，机场停车场约1小时40分；实际还车门店尚未提供，仍按09:00出发、14:00到店预留时间。

   车程口径：基准车程已核查，天气及门店位置仍可能改变实际耗时。

2. **[可选] 海拉尔午餐／附近短逛｜30–60分钟**

   仅在已经到海拉尔、加油和门店安排都清楚时进行。可选一顿蒙古奶茶或当地家常菜，不为热门店长时间排队。

   车程口径：仅选还车点附近；市内额外接驳未计入原高德表。

3. **[优先] 加油、验车、还车｜预留约1小时**

   14:00左右到门店，留出加油核对、行李清点和车辆检查时间；15:00前完成。

   车程口径：不要用高德基础1.5小时车程反推到中午才出发。

**删减顺序：** 有延误就取消海拉尔短逛；不安排湿地、博物馆或远郊景点。
