# 城市吃喝玩乐总结

打开 `itinerary-map.html`，点原地图上的 13 个城市／停靠点钉子，右侧查看四方面总结。窄屏点“城市详情”，手机底部点“城市”。没有新增或复制地图。

- **吃**：餐厅、招牌菜、份量与用餐提醒。
- **喝**：咖啡、奶茶、冷饮；口味、空间和补给便利分开判断。
- **玩**：景点、观景点和沿途线路。
- **乐**：骑马、喂鹿、小火车、文创与早市等参与体验。

右侧没有住宿分类。每项都有综合判断、怎么点／怎么玩、注意事项、适合现有行程哪一天，以及可展开的原帖依据。资料不足时写明缺口，不编店名或排名。未提供店名的内容会明确标为品类或补给线索。

## 排序与筛选

默认只看**高德已核实的固定地点**，按“顺路＋证据”排序：先看驾驶增量可比较的地点，再按正面支持无分歧、有分歧、仅线索、负面反馈分层；每层按额外驾驶 10 分钟内、30 分钟内、更多分组，同组优先证据更强，再比较驾驶时间。可切换推荐作者数、证据强度、额外驾驶排序。支持城市、四类、最低推荐作者数、最多额外驾驶分钟数、店名和关键词筛选。

本轮共有 143 篇去重资料，86 篇用于 116 项总结；其中 70 个不重复固定地点经高德 API 核对，覆盖 77 项吃喝玩乐总结。吃与喝使用同一家店时不重复计地点。未核点的旧条目可取消勾选后查看。

## 高德地点与路线对照

每个核实地点显示高德名称、行政区、地址，以及三种不同距离：到原高德路线折线的几何距离、从既有城市／停靠点锚点驾车过去的距离、加入选定路段后的额外驾驶里程与时间。几何距离不代表能直达。

使用高德地点搜索与驾车 API。人工比对店名、行政区、地址，拒绝不明分店、同名异地、用邻店坐标代替餐厅和标注暂停营业的结果。景区明确使用入口、停车场或游客中心时，会标注驾车终点性质。

插点计算选择关联日期中几何最近的一条原路段，保留起终点和强制途经点，使用推荐策略 32 重新计算基准及插点后的路线。两者相减得到驾驶增量；不是穷举全程后的最小绕行。明显负差意味着高德改选了路线，标“增量待核对”，不进入少绕路排名。原路线与底图保持不变。

数据查询日期为 2026-09-18，不是国庆交通预测。增量不含用餐、游玩、停车和步行。点击“在原图定位”显示选中地点标记；“高德查看”打开该地点。高德登记能确认落点，不保证当天营业，也不等于口味得到支持。没有可归属笔记的固定地点明确标“暂无笔记支持”。

## 推荐证据

每条证据先按具体项目标记：支持、有保留、负面反馈、仅提及。同一篇在同一项目只记一次；同名公开作者保守合并，高度相似正文也合并。无法验证真人身份，不能把这个数量理解为全平台独立用户数。同一作者对同一项目出现混合或负面反馈时，不再计作纯正面推荐。

只有明确支持才计推荐票；路线罗列、未体验、疑似推广不计。缺失点赞、收藏或评论数，不妨碍真实具体的用餐或游览描述作为依据。

- 至少 3 组作者支持、无混合或负面反馈：多篇交叉支持。
- 2 组：两位作者支持；1 组：单篇参考。
- 存在混合或负面反馈：评价有分歧；没有正面支持则标谨慎选择。
- 只有地点提及：仅有提及，推荐数为 0。

这是有限样本的证据强度，**不是统计概率，也不是平台全量榜单**。点赞＋收藏＋评论仍在来源内展示，三项缺一则不计算总量；平台缩写计数注明“约”。来源时间同时展示。历史门票、价格、营业和天气不能作为本次旅行承诺，“行程建议”是结合当前路线作出的安排。

## 继续采集与更新

1. 双击 `启动小红书采集浏览器.cmd`，在该 Edge 窗口正常登录，确认可搜索和打开笔记。
2. 新版搜索页面可先在采集 Edge 中手动打开结果，再运行下方命令读取正常可见的笔记。旧搜索入口若触发验证，不反复重试：

```powershell
python -X utf8 collect_visible_xhs.py
python -X utf8 finalize_city_notes.py
```

3. 阅读新收录的公开正文，在 `curate_city_entities.py` 或 `curate_fixed_entities.py` 中补充具体项目、城市、评价态度和依据。**新增笔记不会自动产生人工总结或推荐票**；避免仅凭关键词把同名店、河流和跨城游记算到错误城市。高德新增关键词写入 `plan_amap_places.py`，查询后人工审核 `select_amap_places.py` 的明确 POI，再计算驾驶增量；不能自动选择第一条结果。
4. 生成并检查：

```powershell
python -X utf8 curate_city_entities.py
python -X utf8 curate_fixed_entities.py
python -X utf8 build_ui.py
python -X utf8 verify_city_guide.py
python -X utf8 verify_city_recommendations.py
python -X utf8 verify_amap_recommendations.py
```

5. 刷新 HTML。数据、样式和脚本内嵌，可离线阅读；打开原文需联网。

CDP 默认连接 `127.0.0.1:9223`，使用本目录的独立浏览器资料。仅读取当前登录会话可正常访问的公开内容与互动数，不导出账号、Cookie 或密码。遇到登录、验证码或访问限制停止，由用户在浏览器正常处理。

默认查询美食、咖啡奶茶、游玩攻略、体验活动，不再搜索住宿。搜索页点赞只用于选择候选；采集按笔记 ID 去重，排除求助和正文信息太少的内容。旧数据保留，每次保存时间、查询词和公开来源。原有一篇历史存档仍保留在资料库，不冒充本轮新采集。

文件：`city-notes.json` 是原始资料库；`city-research/` 保存公开正文证据；`city-entities.json` 保存人工归纳；`city-recommendations.json` 保存去重计票后的展示数据；`build_city_recommendations.py` 计算票数与证据标签。

新增地点和评价修订分别在 `city-fixed-entities.json`、`city-review-additions.json`；高德原始响应在 `amap-recommendation-evidence/`，核点及对照在 `amap-place-audit.json`。证据和 HTML 不含高德 API 密钥。
